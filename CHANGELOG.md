# Changelog

## 2026.10.0

- `package.json` on `main` now carries the same version as the release tag, so the published
  package can be verified against the source. No functional changes.

## 2026.9.0

First release.

- Linkwarden node covering links, collections, tags, highlights, archives, RSS subscriptions
  and the current user. It can be used as an AI Agent tool.
- Find by URL, plus duplicate handling on link create.
- Linkwarden Trigger, a polling trigger for new links with collection and tag filters.
